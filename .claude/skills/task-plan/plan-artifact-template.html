Two buttons on every subtask
  • Ask Claude opens a chat beside the plan, already briefed on that subtask. Drag its left edge to resize it, or switch it to a floating window you can move and resize. It answers from the plan, not your files.
  • Implement starts a new Claude Code session in the desktop app, in the NZWalks folder, filed under the NZWalks sidebar group. It runs the task-implement skill: that subtask only, with the syntax and business reason explained. If the app doesn't open, copy the command into a Claude Code session.
